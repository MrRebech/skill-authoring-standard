# Skill Authoring Standard

Use this skill to create or revise agent skills with a clear relevance filter and consistent structure. It includes a personal template and a shareable template.

## When to use

- When creating a new skill or revising an existing one.
- When preparing a skill for distribution and checking its reuse terms.

## Workflow

1. Define the skill's trigger, outcome, and boundaries.
2. Read `references/authoring-standard.md` and choose the template that matches the intended use.
3. Write the complete common workflow in the skill's `SKILL.md`; link to extra files only when they help with genuinely conditional or shared detail.
4. Check the result using the verification checklist in the reference.

## Boundaries

- For a personal skill, use the lean template.
- Before distributing a skill, use the shareable template, confirm the author name and license, and check that all included material can be relicensed.
- Do not apply CC BY 4.0 to third-party material without permission. Identify third-party content and preserve its original license.

## References

- Read `references/authoring-standard.md` for structure, frontmatter guidance, licensing notes, and verification.
- Use `templates/skill-template.md` for a personal skill.
- Use `templates/skill-template-shareable.md` for a skill intended for distribution.
